# Trademark and brand policy

The Trident **source code** is free software under the AGPL-3.0 (see
[LICENSE](LICENSE)). The Trident **brand** is not covered by that license.

The following remain the property of Eastechs, LLC and are **not** licensed
under the AGPL:

- The name "Trident" as it identifies this application
- The Trident application icon and other brand artwork in `resources/images/`
- The domain tridenthq.app

## What this means in practice

**You may**, without asking:

- Use, modify, and redistribute the source code under the AGPL
- Say truthfully that your project is "based on Trident", "a fork of Trident",
  or "compatible with Trident"
- Write about, review, teach, or screenshot Trident
- Build the app from source for your own use, unchanged brand and all

**Please do not**:

- Distribute a modified build under the name "Trident" or with its icon
- Use the name or icon in a way that suggests Eastechs, LLC published,
  endorsed, or supports your version
- Register confusingly similar names, domains, or app listings

If you fork and distribute Trident, pick your own name and icon. Everything
else in the repository is yours to use under the AGPL.

## Why

The point is not to restrict the code — the AGPL already governs that, and
copyleft means your fork stays free too. The point is that users downloading
something called "Trident" should be able to know whose build they are running,
particularly for an application that handles their API keys.

Questions, or an unusual case worth discussing: <licensing@eastechs.com>.
